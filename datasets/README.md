## 2015 Flight Delays and Cancellations Dataset

Source: Kaggle
Dataset: 2015 Flight Delays and Cancellations
Link: https://www.kaggle.com/datasets/usdot/flight-delays?select=flights.csv

Download the dataset from the original source and place the three files in:

D:\Projects\DATA PROJECTS\SQLWarehouseProject\datasets\airlines.csv
D:\Projects\DATA PROJECTS\SQLWarehouseProject\datasets\airports.csv
D:\Projects\DATA PROJECTS\SQLWarehouseProject\datasets\flights.csv

or create your own path and modify the path in the bronze.proc_load_bronze.sql script 
in the bulk insert sections accordingly.
